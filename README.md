# 皮影新生 · ShadowPlay

当前在线版 **v1.1.0**：[打开游戏](https://sheezy04.github.io/piying-webgl/)。Unity 2022.3.62f3c1 WebGL，使用桌面浏览器运行。

通过三根签子操演皮影，完成蓝影示范、跟练、姿态与节奏反馈，再重练误差最大的片段。自由操演和五回合挑战共用同一套控制。武生为主角，小生为配合对手。

## 操作

| 功能 | 鼠标 | 键盘 |
|---|---|---|
| 选择身体 / 左手 / 右手 / 双手 | 底栏按钮 | Tab |
| 移动所选部位 | 舞台左键拖动 | WASD / 方向键 |
| 旋转所选部位 | 滚轮 | Q / E |
| 开始跟练 / 推进教学 | 阶段按钮 | 空格 |
| 切换动作 | 换动作 / 下一招 | 1–6 |
| 复位 | 复位按钮 | Backspace |
| 速度 0.5× / 0.75× / 1.0× | 速度按钮 | B |
| 身体移动时手跟随 | 跟随按钮 | M |
| 返回 | 页面返回入口 | Esc |

鼠标和键盘均可独立操演。选“双手”即可同时移动两手；滚轮旋转无需持续按住鼠标。

## 玩法

- 跟师学艺：示范结束后开始跟练；有效评分页可进入“练最差段”。过短、未活动或数据不足的动作会显示原因及重试入口。
- 自由操演：自由移动、旋转与录制。浏览器不直接写入 Unity 工程资产。
- 影武者挑战：入场后自动开始，空格可跳过等待；五回合后可再战、回操演或首页。60 分接招、90 分完美。
