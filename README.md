# 皮影新生 · ShadowPlay（WebGL 在线版）

一台可以用鼠标"演"的皮影戏：三根签子操纵十五个关节的皮影，DTW 逐帧对齐评分，影子对手五刀回合制武打。

**▶ 在线游玩：打开本仓库的 GitHub Pages 地址即可开始。**

## 操作

| 操作 | 方式 |
|---|---|
| 移动签子 | 鼠标左键拖动（自动抓最近的签） |
| 捻转签子 | 按住拖动时滚轮 |
| 双手齐动 | Shift + 拖任一手签 |
| 推进流程 / 开始 | 空格 |
| 切换跟练速度 | B（0.5× / 0.75× / 1.0×） |
| 选动作 | 1 ~ 6 |
| 退出 / 逐级返回 | Esc |

## 玩法

- **跟师学艺**：蓝影示范 → 追影跟练 → 出分点评；评分页可一键"练最差段"（金影回放你的动作，单独重练误差最大的片段）。
- **自由操演**：无目标推签游玩，可录制并烘焙成新动作。
- **影武者挑战**：对手起手是预告，时限内摆出格挡/闪避/反击姿态，五刀结算。
